The handoff

Card urgency first. Cloud urgency second.

A slow network should not hold the card hostage. DDump separates the verified local copy from backup delivery so the next shoot can keep moving.

01 / DETECT

Insert the card

Trusted camera media can start automatically while unrelated drives stay ignored.

02 / COPY

Stage locally

Recent media moves to your chosen Dump Folder before slower backup work begins.

03 / VERIFY

Prove the copy

File-size checks are standard. SHA-256 verification is available when you want it.

04 / CONTINUE

Eject and move

The card becomes safe while pending backups remain visible and recoverable.
