DDump

Photo card ingest for Mac

DDump copies camera cards into safe local staging, groups files by shoot, moves them to your destination, verifies the copy, and handles retries so you can eject cards with less babysitting.

Download + install

  1. Download the latest DDump.dmg from the shared link or GitHub Releases.
  2. Open the DMG, then double-click Install DDump.command.
  3. Open ~/Applications/DDump.app. If macOS blocks it, approve DDump in System Settings → Privacy & Security → Open Anyway.
  4. Open Settings before the first real card and choose your Dump Folder and Backup Folder.

First setup

  1. General: choose a Dump Folder on this Mac or a fast connected SSD.
  2. Backup: choose Google Drive Desktop, Dropbox, Box, OneDrive, iCloud Drive, pCloud, NAS, or another local folder.
  3. Naming: use Smart, Calendar, Cluster, Sequential, or Custom names.
  4. Calendar: Mac Calendar is the recommended public setup because it works offline with calendars already synced to the Mac.
  5. Notifications: use Mac alerts or ntfy phone alerts for card ejected, backup complete, and integrity warnings.

Using it

  1. Insert an SD card. DDump scans for recent photo/video files.
  2. Approve/trust the card if DDump asks.
  3. Watch the checklist: staging copy, eject, destination upload, verified done.
  4. Optional: type a shoot name while transfer is running and click Use name.
  5. Use Retry Pending Uploads if internet or destination storage was unavailable.

What it handles

  • Whole-card media detection for Canon, Sony, Fuji, Panasonic, DJI, GoPro, and other camera-card shapes.
  • Capture-time clustering for multiple shoots in one day.
  • Calendar naming with local Mac Calendar first, plus optional Google Calendar OAuth.
  • Smart date folders like 2026/2026.06/2026.06.07.
  • Local staging receipts, pending upload recovery, and destination verification.
  • Settings → General → Troubleshoot checks card detection, folders, calendar access, and skipped-card reasons.
Best first test: use a small card or a test folder, confirm the destination folder appears, and check that DDump marks “All complete” before trusting it for paid work.
Need help? Open DDump, click Log, and send the newest lines plus a screenshot of the main window. Most issues are destination permissions, Google Drive availability, or a card that has not been trusted yet.
